# 🎮 GameHub - Matchmaker & Library Manager

## 📌 Análise do Produto
O GameHub é uma plataforma leve focada em vídeo-games que resolve o problema de jogadores que buscam parceiros ou querem montar equipes online para jogar seus títulos favoritos.

## 📋 Especificação de Requisitos
- **RF01 - Cadastro de Perfil:** O sistema deve permitir o cadastro de jogadores informando seus nicknames e jogos favoritos.
- **RF02 - Criação de Salas:** O sistema deve permitir a criação de salas de busca de partida associadas a um jogo específico.
- **RF03 - Listagem de Status:** O sistema deve exibir a lista de jogadores ativos e salas disponíveis em tempo real na memória.

## 🚀 Como Executar o Programa
1. Certifique-se de ter o **Python** instalado.
2. Execute o arquivo pelo terminal com o comando:
   ```bash
   python app.py
   ```
